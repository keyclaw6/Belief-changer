# Chapters

Finished chapters land here as `chapter-01.md`, `chapter-02.md`, … — built up **one at a time**, in order.

Each chapter-writer receives exactly four things (the anti-repetition context strategy):
1. The **master plan** (`../master-plan.md`) — whole-book oversight.
2. The **target chapter card** — the semantic authority for this chapter.
3. The **immediately previous chapter only** — local continuity.
4. The **style guide** (`/prompts/style-guide.md`) — voice & method.

Each chapter is then judged by the judge sub-agents (which verify presence and effect themselves) before the next chapter begins.
