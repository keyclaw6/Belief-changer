# Production Books

Books **generated by the Belief-Changer pipeline** live here — **one project folder per book**. Reference source texts live elsewhere (in [`/analysis/reference-books/`](../analysis/reference-books/)); this folder is only for books we produce.

## Starting a new book
Copy the template, then fill it in order:
```
cp -r production-books/_template production-books/<book-slug>
```
`<book-slug>` is lowercase-hyphenated (e.g. `quit-gaming`, `quit-doomscrolling`).

## The per-book folder structure (always the same)
```
production-books/<book-slug>/
├── README.md                    # project overview, status, artifact index
├── 00-brief.md                  # topic, reader, goal, fork decisions
├── research/
│   ├── research-log.md          # chronological log of every search (preserves order found)
│   ├── sources/                 # raw source dumps (any format) — one file per source; synthesized later
│   ├── lived-experience.md      # synthesized from sources/: why they do it / can't stop / shame / testimonials
│   └── scientific-evidence.md   # synthesized from sources/: studies & mechanisms (supported vs contested)
├── master-plan.md               # chapter-by-chapter blueprint (the master-plan skill's output)
├── master-plan-review.md        # fresh independent reviewer critique + resolution (REQUIRED)
└── chapters/
    └── chapter-01.md, chapter-02.md, …   # built one/two at a time, in order
```

## The flow (artifacts accumulate in this order)
1. **Brief** — define the behavior, reader, and the fork decisions (`00-brief.md`).
2. **Research** — sub-agents mine raw source packets into `research/banks/` (with verbatim sources in `research/sources/`), logged in `research-log.md`; the lead then synthesizes them into `lived-experience.md` and `scientific-evidence.md`.
3. **Master plan** — run the master-plan skill (`/prompts/master-plan-skill-v2.md`) → `master-plan.md`. The plan-writer pulls in `/prompts/style-guide.md` + this folder's research and derives the book-specific adaptation (style guide §4 forks + §10 playbook) directly; it is **refined via its required fresh independent review gate** (`master-plan-review.md`, ending "fit to write from").
4. **Chapters** — write one at a time, in order. Each chapter-writer sees only the master plan + the target chapter card + the previous chapter + the style guide.

> Canonical references used throughout (global, never copied per book): the **style guide** `/prompts/style-guide.md` and the **reference-book analyses** `/analysis/`.
