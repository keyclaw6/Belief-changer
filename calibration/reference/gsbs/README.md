# GSBS Reference — Good Sugar Bad Sugar (Allen Carr)

Chapter-level extraction of the real book, from
`analysis/reference-books/The easyway Good Sugar Bad Sugar.epub`.
This is the calibration ground truth the judge panel compares against.

- `00-introduction.md` — the introduction (John Dicey)
- `chapter-01.md` … `chapter-20.md` — the 20 chapters, spine order
- Front matter (cover, title, dedication, copyright, TOC) and back matter
  are deliberately omitted — they are not judging material.
- ~59,500 words total.

Read-only. Never edited by the loop. Chapter mapping to our book is
content-based via `loop/reference-alignment.md` — never mechanical offset.
