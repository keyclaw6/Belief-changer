# Vision — v2

Build an accessible, nonprofit, original belief-change book factory. Serve informed reader goals across subjects and languages with truthful evidence, accurate lived texture, coherent progression and practical agency.

The immediate product is a validated pipeline, not an author-copying system or a universal treatment claim. Work on strong research, clean role contracts, complete manuscripts, independent final audit and honest outcome measurement before scaling distribution.

`docs/BOOK-FACTORY-VISION.md` defines the expected reading experience. `docs/FACTORY-V2.md` defines operation and current limits. `loop/PROGRAM.md` defines experiments. Historical plans for community distribution, EPUB and audio remain ideas, not implemented features of this upgrade.
