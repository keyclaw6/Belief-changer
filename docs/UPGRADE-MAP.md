# Audit → implementation → verification

The owner requested implementation after the campaign-001 audit. This upgrade replaces active runtime contracts rather than adding a fiftieth layer of prohibitions. Exact old operational files are archived; all historical iterations, scores, source assets and production chapter files are preserved.

## Boundaries of this implementation

Automated validation enforces structure, scope declarations, artifact integrity and fail-closed workflow. It cannot establish the truth of source content, prove that imported metadata came from a particular provider/human, determine copyright clearance or demonstrate real reader outcomes. Those remain explicit, non-bypassable review/experimental requirements in the workflow, not fabricated test results.

The external evaluator has not been chosen for the owner. Human calibration and qualified publication approval have not been invented. The legacy source corpus has not been reverified, and old manuscripts have not been silently rewritten. The new architecture's quality improvement must be measured in the next authorized controlled campaign. No medical/behavioral effectiveness claim follows from this upgrade.

Verification results and the inspected commit/tree identities are recorded under reviews/v2-upgrade/. The full ZIP retains historical evidence under its existing rights while excluding credential files and Git internals.
