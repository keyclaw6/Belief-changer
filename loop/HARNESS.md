# Harness bindings

The host autoresearch controller follows `skills/running-auto-research-loop/SKILL.md`; its canonical launch command creates/resumes a saved top-level Pi session per book in a PTY. The existing host durable command controller owns process lifetime. No fixed systemd unit name or old launcher script is experimental authority.

`factory/config.json` and each run’s frozen copy own model routes. All live model execution remains OpenCode Go only, with an independent evaluator family. A command adapter, where explicitly configured, is only a trusted Go transport and must return actual metadata; it is not a fallback model worker. The current launch helper uses the configured HTTP profiles.

`docs/RESEARCH-ACCESS.md` owns research setup: default working bridge, optional cloak, actual lane behavior checks. Do not duplicate provider availability, login status or browser policy here.
