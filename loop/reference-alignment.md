# Reference Alignment — Our Chapters ↔ GSBS Chapters

Maps every chapter of our quit-sugar book to the GSBS chapter doing the
same belief-work (`calibration/reference/gsbs/`). Content-based — NEVER a
mechanical offset. The chapter judges compare against the aligned real
chapter; the book-arc judge uses this table as the GSBS skeleton.

## Procedure

1. Read each of our chapter cards' primary job, entering belief, and
   leaving belief from the accepted `master-plan.md`.
2. Read each plausible GSBS chapter far enough to identify its belief move
   and reader-state transition.
3. Select the closest real chapter by belief-work, not position. Mark an
   imperfect comparison `PARTIAL` or `WEAK`; never replace the real
   comparison with an internal-memory comparison — judges always receive a
   real chapter.
4. Complete this table after the plan is accepted and before any judging.

## Rebuild rule

This table is frozen while the accepted plan is unchanged. When an accepted
iteration changes the master plan, rebuild the table with the same
procedure before judging. A rebuilt table moves the comparison target:
position-specific comparisons reset, and cross-iteration regression checks
remain valid only at the failure-class level (which is how decisions are
made anyway).

## Alignment quality

- STRONG: same belief-move, same emotional function, same reader position
- PARTIAL: same belief-move, different approach or reader position
- WEAK: related but not equivalent — judges weight the comparison lightly
  and lean on the method definitions in their prompts
