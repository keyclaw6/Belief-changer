# Hypothesis — Iteration 053 (v2 architectural baseline A)

## Purpose

Begin the newly authorized five-iteration campaign (053–057) with a fresh, noise-aware v2 baseline before testing factory changes.

Iteration 053 establishes **Condition A** from docs/EXPERIMENTS-AND-READERS.md:

- writer contract: current/complex contract
- editorial context: local chapter review

This is an exploratory training baseline, not a release candidate and not evidence of reader efficacy.

## H-053

Under the current v2 factory, repeated generation on the two known development subjects will expose enough generation/judge variance and recurring factory-level defects to support a falsifiable next intervention without relying on a single lucky book draw.

The baseline is informative only if the same frozen inputs produce measurable repeatability information and the independent judge can distinguish stable defects/strengths from replicate noise.

## Subjects and sampling

Development subjects:
- quit-sugar
- quit-smoking

For exploratory screening, use the same frozen brief, research, accepted plan, generator configuration and current factory contract within each subject.

Sample allocation:
- 3 independent generation replicates per subject for the selected architectural screening work
- selected work should cover opening, mechanism, strongest objection, handoff and ending positions where the runtime permits fixed-context screening
- preserve actual preceding manuscript context for any manuscript-dependent task
- no adaptive extension of the sample after seeing results

If the reusable factory requires complete-book execution to preserve its integrity, run complete books rather than weakening the factory boundary.

## Evaluation

The outer controller, not the Pi factory, owns evaluation.

- external evaluator: GPT-5.6 Sol / OpenAI family through the host ChatGPT harness, recorded honestly in metadata
- generator family must remain independent from the evaluator family
- use blinded comparisons with order reversal where pairwise comparison is applicable
- record same-condition replicate disagreement as generation variance rather than attributing it to the factory change
- ties are allowed
- do not promote or update factory/champion.json from this exploratory baseline

Primary diagnostic dimensions:
- argument
- recognition
- progression
- voice
- emotional_movement
- economy

Also retain final-audit critical findings and recurring revision classes.

## Frozen boundaries

Before paid generation:
1. live research preflight must be READY for each real subject;
2. every real run must freeze its preflight, brief, research, code, prompts and config;
3. missing independent evidence/final review fails closed;
4. the Pi factory owns research through COMPLETE_UNRELEASED and the outer controller stays hands-off while healthy;
5. infrastructure failures resume the same durable factory session rather than synthesizing role outputs.

Human calibration is still pending, so this campaign is optimization/exploration only unless real calibration is supplied later. It must not create a validated release claim.

## Success / falsification for 053

SUPPORT as a useful baseline if:
- all required gates are real and pass without bypass;
- at least two independent replicates per subject complete with valid independent audits;
- replicate judgments expose stable preserved strengths and/or recurring defects that can be separated from obvious draw variance;
- no hidden factory-stage synthesis or evaluator-family leakage occurs.

MEASURE_MORE / BLOCK rather than inventing learning if:
- live research access is not READY;
- evaluator independence cannot be maintained;
- the factory cannot reach valid COMPLETE_UNRELEASED outputs;
- observed differences are dominated by unstable replicate/order effects with no coherent transferable signal.

No factory change is made in 053 itself.
